## Non-negotiable project rules

These are abbreviated reminders only; `agents.md` is authoritative.

- The orb must never accept keyboard focus: no orb `set_focus`, no `<button>`, `<input>`, or `tabindex` in its DOM.
- There must be no `unwrap`, `expect`, or `panic!` in application code. The strict Clippy gate enforces this.
- Renderer code only renders backend state and invokes commands. It never owns domain decisions or persistence.
- `session/` must stay pure: no Tauri, SQL, Win32, or system clocks.
- Do not add dependencies without the required explicit decision.
- Keep colours, font sizes, and UI durations in `src/lib/tokens.css` only.
- Never edit `src/ipc/bindings.ts` by hand. It is generated by Rust via tauri-specta.
- Never log window titles, task/thread text, dump content, or notes. The app has no network calls.
- Use `apply_patch` for source edits. Keep commits small and conventional.

- `src-tauri/src/config.rs`: `%APPDATA%\Trident` paths, log directory, and database path.

- `src/ipc/bindings.ts`: generated, committed IPC contract.

## M1 delivered

M1 implements the non-activating static orb and placement behavior.

### Backend

- `src-tauri/src/platform/win32.rs` is the only M1 unsafe Win32 code. `set_no_activate` applies `WS_EX_NOACTIVATE`, `WS_EX_TOOLWINDOW`, and `WS_EX_TOPMOST`, checking `GetLastError` after both style APIs and returning named `AppError::Platform` failures.
- `src-tauri/src/windows/orb.rs` obtains the existing hidden orb, applies the Win32 style **before** showing it, restores/clamps saved placement, registers movement and DPI event handlers, then shows it.
- Orb placement is persisted as JSON in the existing SQLite `settings` table under `orb.position`. It stores monitor name, physical X/Y, and optional dock edge. Malformed saved JSON is ignored with a safe warning and replaced on the next successful save; its contents are never logged.
- `src-tauri/src/windows/positioning.rs` contains pure geometry: work-area clamping, 64px edge docking, and saved-monitor resolution with primary-monitor fallback. It has no Win32/Tauri dependency.
- `src-tauri/src/commands/orb.rs` exposes `orb_begin_drag` and `orb_dropped(physical_x, physical_y)`. They reject requests from any non-orb window, log backend errors, and do not expose focus behavior.
- `src-tauri/src/db/mod.rs` now has `setting_value` and `set_setting_value`; these are generic helpers over the pre-existing `settings` table.
- `AppState` is cloneable and exposes the database to the window layer only for this M1 position persistence path.

### Frontend

- `src/windows/orb/OrbRoot.tsx` remains a static pill. It is a non-focusable `<div role="button">` with pointer handlers only.
- Pointer down invokes `orbBeginDrag`; pointer up reads Tauri’s physical `outerPosition()` and invokes `orbDropped(x, y)`.
- `src/lib/tokens.css` adds only drag cursor and `user-select: none` behavior; all visual tokens remain centralized.
- `src/windows/orb/OrbRoot.test.tsx` verifies both the absence of focusable controls and physical-coordinate drag IPC.
- `src/ipc/bindings.ts` was regenerated by running the app after Rust command changes. Never hand-edit it.

### TypeScript generation note

Tauri-specta emits unused event-channel helpers into generated bindings when there are no events. Once the orb imported the generated client, TypeScript had to check that file and `noUnusedLocals: true` failed on generator-owned declarations. `tsconfig.json` therefore sets `noUnusedLocals` to `false`; ESLint remains enabled. Do not solve this by modifying `bindings.ts`.
